Importar as imagens das campanhas

Ferramenta de importação para o Supabase. Lê o ZIP de imagens no teu computador, envia cada ficheiro para o bucket scene-images e associa-o ao local correto.

1. Preparar o catálogo

Executa primeiro supabase/variantes_locais.sql no SQL Editor. Este passo permite duas variantes por local sem apagar imagens antigas.

2. Selecionar o ZIP

Por omissão, os ficheiros existentes são preservados. Para substituir as imagens antigas, ativa a opção acima. Não é feita qualquer chamada à OpenAI durante a importação. As imagens do pacote são uma primeira coleção de pré-visualizações; podem ser substituídas posteriormente com uma ferramenta de gestão.
